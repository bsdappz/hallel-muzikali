# הלל מוזיקלי — גרסה ראשונה (v1)

אפליקציית Next.js (App Router) בעברית, RTL, בפלטת קרם+זהב.
הצפייה פתוחה לכולם בלי הרשמה. בגרסה זו ההוספות נשמרות בדפדפן
בלבד (localStorage) — אין עדיין חשבונות, שרת או בסיס נתונים.

## מה יש באפליקציה

- **דף הבית (`/`)** — תפילות קרובות בלבד (לעולם לא תפילות שעברו),
  בתצוגת כרטיסים, עם פלייס־הולדר לפלייר, כפתור ניווט לגוגל מפות
  לפי הכתובת, לייקים, חיפוש וסינון לפי עיר/תאריך/שעה.
- **ספריית מנגינות (`/melodies`)** — תצוגת רשימה, סינון לפי מזמור
  או לפי תגי זמנים בשנה, ממוינת לפי לייקים (הטובות למעלה).
- **עמוד מנגינה (`/melodies/[id]`)** — מילים עם אקורדים מעל המילים,
  מעל כל שורה; כפתור יוטיוב; לייק.
- **עמוד חזן (`/chazzanim/[id]`)** — המנגינות שלו + התפילות הקרובות
  שהוא מוביל.
- **הוספת מנגינה (`/add-melody`)** — בחירת חלק בהלל, שם שיר, בחירת
  סולם (ברירת מחדל Am, נבחר פעם אחת לשיר ומשפיע על כל האקורדים),
  תגי זמנים, ועורך האקורדים הנבחר — עיצוב א: גע במילה, גע באקורד
  בפאנל התחתון, והאקורד נוחת מעל המילה. הפאנל מציג שתי קבוצות:
  אקורדי הסולם + נפוצים מחוץ לסולם (ב־Am: D, Bb, A, E7).
  חיפוש בפאנל מאפשר כל אקורד (Amaj7, מוקטן וכו') — אלו לעולם לא
  מופיעים בפס הראשי. יש גם מצב רשימת אקורדים פשוטה בלי מיקום.
  מילון הסולמות: `app/lib/chord-scales.json`.
- **הוספת תפילה (`/add-performance`)** — שדות חובה: תאריך, שעת
  תפילה, שם בית כנסת, כתובת מדויקת. אופציונלי: חזן, פלייר
  (ב־v1 תצוגה מקדימה בלבד, הקובץ לא נשמר).

## נתוני דמו

5 תפילות (ירושלים ×3, צפת, חברון), 4 מנגינות, 2 עמודי חזנים.
התאריכים עתידיים ביחס ל־26 באוקטובר 2026 והם להמחשה בלבד.
פלייס־הולדרי הפליירים הם גרדיאנטים ב־CSS עם תו מוזיקלי — לא
תמונות חדשותיות (שיקולי רישוי); במקומם יופיע הפלייר שיועלה.

## הרצה מקומית

```bash
npm install
npm run dev
```

ואז לפתוח http://localhost:3000

## בניית גרסת ייצור (בדיקה)

```bash
npm run build
npm start
```
